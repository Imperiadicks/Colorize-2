# Colorize 2

Необходимые дополнительные аддоны:

1. [Colorize2Core](https://github.com/Imperiadicks/Colorize2Core) — Colorize2Core: динамическая палитра, фон, контраст кнопок и остальные эффекты. ID `31c62ba2-b6f6-4ba7-934e-39146eccfe69`.


## Структура

`src/` — исходники темы; `addon/` — содержимое пакета; `scripts/` — сборка и установка.
`dist/` и `node_modules/` создаются командами `pnpm install` и `pnpm build`, в исходники не входят.
